| `WorkEvents.tsx` | `WorkEvents`:工作页右侧的「动态」面板——这个 work 轨迹的列表视图(`useTrace` → `GET /works/{id}/trace`,OTLP 的段 + 点,5 秒刷新,新的在上;docs/designs/v5/work-trace.md §6):一行是段的开始、段的结束(开着的段只有开始)或一个点,按纳秒时间排(BigInt 比;同一时刻开始 < 点 < 结束,再按接口先后)。`work` 段的开始是创建(带 link / `memorytalk.work.reopened` 的是重新打开),结束是归档;`worklet` 段的开始是打开(在哪一列),结束按 `memorytalk.end.reason` 分关闭(关时在哪一列,`memorytalk.end.column.*`)/ 归档时关闭 / 自己退出了(`gone`,不写谁);点有加 / 改别名 / 删列(`column.*`)、挪动工作单元(`worklet.moved`,分换列和同列换位,第 n 个 = `memorytalk.index` + 1)、关掉时段已经结束了的工作单元(`worklet.closed`,写法同关闭)、改目标(`work.renamed`)。列标记写成当时的别名或 `列 n`;工作单元叫什么从它的 worklet 段取(点按 `spanId` 找段);每条下面一行是 `谁 · 时间`(开始 / 点取 `user.id`,结束取 `memorytalk.end.user.id`,没有就 `user.id`)。agent 轮次(`agent.turn`)默认藏起来,顶上一个按钮切换;认不出的段 / 点原样显示名字和属性 |
| `Workspace.tsx` | `Workspace`:一个 work 的页面——头部(目标,右边是除自己外还有谁在看 `Viewers`,来自 `work.viewers`;拆分、归档在侧栏每行的「⋯」里)。在看的心跳就是 `useWork` 15 秒一次的 `GET /works/{id}`;`usePresence` 在关页面(`pagehide`)、换 work、离开工作页时发 `POST /works/{id}/users/leave`(fetch keepalive 带 Bearer;卸载时推到下一拍,StrictMode 的立刻重挂会撤掉它)。下面是**几列,每列从上到下摆工作单元卡片**——列只承载弱编排,没有别的布局对象。`arrange()` 把列清单(`['columns', id]` ← `GET /columns`,按 `position` 从左到右)和工作单元清单(`['worklets', id]`,每个带 `column` / `position` / `collapsed`)摆到一起:每列放 `column` 指向它的工作单元,按 `position` 从上到下;不在任何一列上的(正常没有)补到最左一列末尾。两个清单都 8 秒刷新。编排改动**一个动作一个请求**(`op`:加列 `POST /columns` 带 beside + side、改别名 / 收起列 `PATCH /columns/{c}`、删列 `DELETE /columns/{c}`,交回列清单;挪 `POST /worklets/{w}/move` 带 column + index、收起工作单元 `PATCH /worklets/{w}`,交回工作单元清单),成功就用交回的清单替换对应缓存并刷新动态(`['trace', id]`),失败提示并重拉两个清单;编排动作和新建工作单元**排队一个一个发**(同一个 mutation scope `arrange-<id>`,上一个的 onSuccess 跑完下一个才发),后到的回包一定读到了前面所有动作,不会拿旧清单盖掉新的;工作单元可收起、拖动标题上的移动把手挪到任一列任一位置(聚焦把手按方向键也行);列可收起成窄边,空了才能删;列标题有别名只显示别名、没有显示 `列 <编号>`(编号来自列 id,不按位置;前面不带图标),点一下就地改别名(`ColumnName`,无边框输入,编号不动,清空回到 `列 <编号>`);每列底部一排:左边加一列 / 添加工作单元 / 右边加一列;「添加工作单元」弹出 `NewWorklet`(弹层里像浏览器新标签页:上面一条地址栏,块即 URI;下面几块应用,点一块只是把 URI 填进地址栏,回车或「打开」才建),建时带上 `column`,直接进那一列;建好刷新工作单元清单和动态 |
| `WorkletBody.tsx` | `WorkletBody`:一个工作单元的身体——终端(iframe 装 tmuxd 交回的 ttyd 地址)/ agent 的对话记录 / 网页 iframe;复制地址、新窗口打开、重连、结束工作单元(重连 / 结束后刷新工作单元清单和动态) |
