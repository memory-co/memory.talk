# works / canvas — 画布是视图:列 × 工作单元,乐观锁

## 这个场景在测什么
画布的形状是几列、每列从上到下摆工作单元(可收起)。从未写过 = version 0 空;`PUT` 全量覆盖,`version` 必须等于当前否则 409,成功后 +1;
列 id 重复、一个工作单元出现两次 → 409。画布不建、不删工作单元,但跟着工作单元走:开一个工作单元就进第一列末尾(没有列就建 `c1`),关掉就从格子里拿掉。
